# Asistanım 1.0
Kotlin + Jetpack Compose Android başlangıç uygulaması.

Özellikler: Türkçe sohbet arayüzü, sesle giriş (Android konuşma tanıma servisine bağlı), sesli yanıt (TTS), yerel not kaydetme/listeleme, saat sorgusu ve desteklenen uygulamaları açma.

Not: Bu ilk sürümde gerçek bir bulut LLM bağlantısı yoktur. API anahtarları uygulamanın içine gömülmemelidir. Çevrimdışı genel sohbet modeli de henüz dahil değildir.
